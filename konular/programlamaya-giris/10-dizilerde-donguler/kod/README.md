# 10. Hafta — Örnek Kodlar

| Dosya | Konu |
| ----- | ---- |
| `01-dizi-gezme.cs` | `for` ve `foreach` ile gezinme |
| `02-toplam-ortalama.cs` | Kumbara algoritması |
| `03-en-buyuk-en-kucuk.cs` | "Kral kim?" ve başlangıç değeri tuzağı |
| `04-arama.cs` | Bayrak değişkeni, `break`, indis bulma |
| `05-degistirme.cs` | Neden `foreach` ile değiştiremiyoruz? |

## Çalıştırma

```bash
dotnet run 03-en-buyuk-en-kucuk.cs
```

## Denemeniz için

- `01-dizi-gezme.cs` içinde `i < Length` yerine `i <= Length` yazın. Ne oluyor?
- `02-toplam-ortalama.cs` içinde `(double)` çevrimini silin. Ortalama ne oluyor?
- `03-en-buyuk-en-kucuk.cs` sonundaki negatif dizi örneğini açın.
  Başlangıç `0` olunca sonuç neden yanlış?
- `04-arama.cs` içinde `break` satırını silin. Sonuç değişiyor mu?
  Peki program kaç tur fazladan dönüyor?
- `05-degistirme.cs` içindeki `foreach` bloğunu açın. Derleyici ne diyor?
