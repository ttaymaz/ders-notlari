# 4. Hafta — Örnek Kodlar

| Dosya | Konu |
| ----- | ---- |
| `01-if-temel.cs` | En basit `if` |
| `02-tek-cift.cs` | `if-else` ve `%` operatörü |
| `03-harf-notu.cs` | `else if` zinciri ve **sıra neden önemli** |
| `04-switch-gun.cs` | `switch-case`, çoklu `case`, `default` |
| `05-birden-fazla-kosul.cs` | `&&` ve `\|\|` ile birleşik koşullar |

## Çalıştırma

```bash
dotnet run 02-tek-cift.cs
```

## Denemeniz için

- `01-if-temel.cs` içine negatif bir sayı girin. "Program sona erdi" yazıyor mu?
  Neden?
- `03-harf-notu.cs` sonundaki ters sıralı zinciri deneyin. 95 girdiğinizde neden
  `CC` yazıyor? Bu kod derleniyor — derleyici sizi neden uyarmıyor?
- `04-switch-gun.cs` içinde bir `break;` silin. C# ne diyor?
- `05-birden-fazla-kosul.cs` içinde `&&` yerine `||` yazın. Kimler geçer oldu?
