# 3. Hafta — Örnek Kodlar

| Dosya | Konu |
| ----- | ---- |
| `01-kullanicidan-veri.cs` | `Console.ReadLine()`, metin araya ekleme |
| `02-toplama.cs` | Tip dönüşümü, `Convert` ve `Parse` |
| `03-bolme-tuzagi.cs` | Tam sayı bölmesi tuzağı ve `%` operatörü |
| `04-operatorler.cs` | Aritmetik ve atama operatörleri |

## Çalıştırma

```bash
dotnet run 01-kullanicidan-veri.cs
```

## Denemeniz için

- `02-toplama.cs` içinde sayı yerine **harf** girin. Ne oluyor? Bu hatayı
  düzgün yakalamayı 13. haftada öğreneceğiz.
- `02-toplama.cs` sonundaki yorum satırını açın. Dönüştürmeden toplarsak
  `5` ve `3` neden `53` oluyor?
- `03-bolme-tuzagi.cs` içinde `7 / 2` neden `3` veriyor? Sonucu `3.5` yapmanın
  kaç farklı yolu var?
- `04-operatorler.cs` içinde `sayac++` yerine `++sayac` yazın. Bu örnekte fark
  var mı? Peki `Console.WriteLine(sayac++)` yazsanız?
