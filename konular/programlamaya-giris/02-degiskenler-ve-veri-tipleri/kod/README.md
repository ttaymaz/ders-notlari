# 2. Hafta — Örnek Kodlar

| Dosya | Konu |
| ----- | ---- |
| `01-merhaba-dunya.cs` | İlk program, `Console.WriteLine` |
| `02-degiskenler.cs` | Değişken tanımlama ve değer atama |
| `03-veri-tipleri.cs` | Temel veri tipleri, tırnak kuralları, kasıtlı hatalar |

## Çalıştırma

```bash
dotnet run 01-merhaba-dunya.cs
```

Visual Studio'da konsol projesi açmak isterseniz kodu `Program.cs` içine
yapıştırmanız yeterli — üst düzey ifadeler her iki yolda da aynı çalışır.

## Denemeniz için

- `01-merhaba-dunya.cs` sonundaki noktalı virgülü silin. Hata ne diyor?
- `02-degiskenler.cs` içinde `yas` değişkenine değer atamadan yazdırmayı deneyin.
  C# buna neden izin vermiyor?
- `03-veri-tipleri.cs` dosyasının sonundaki yorum satırlarını tek tek açın.
  Beş farklı hata mesajı göreceksiniz — her birini okuyun.

Hata mesajları düşman değil, yol tarifidir. Okumayı öğrenmek bu dersin
en değerli becerilerinden biri.
