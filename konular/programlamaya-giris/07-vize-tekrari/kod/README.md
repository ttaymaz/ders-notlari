# 7. Hafta — Tekrar Alıştırmaları

| Dosya | Ne yapacaksınız |
| ----- | --------------- |
| `01-cikti-tahmini.cs` | Çıktıyı **önce kağıda yazın**, sonra çalıştırın |
| `02-negatif-toplam.cs` | Algoritmanın koda nasıl döndüğünü inceleyin |
| `hatali/hata-avi.cs` | 7 hatayı bulun ve düzeltin |

## Nasıl çalışmalı?

**`01-cikti-tahmini.cs`** sınavın A bölümündeki soru tipidir. Yedi bloğun her
birinin çıktısını tahmin edin, sonra çalıştırıp kontrol edin. **Yanıldığınız
blok, tekrar etmeniz gereken konudur.**

| Blok | Konu | Yanıldıysanız |
| :--: | ---- | ------------- |
| 1 | Tam sayı bölmesi, `%` | 3. hafta |
| 2 | Döngü sınırları | 5. hafta |
| 3 | `else if` sırası | 4. hafta |
| 4 | `x++` — önce yazdır, sonra artır | 3. hafta |
| 5 | `do-while` en az bir kez | 5. hafta |
| 6 | İç içe döngüde `break` | 6. hafta |
| 7 | `+` operatörü ve veri tipi | 3. hafta |

**`hatali/hata-avi.cs`** kasıtlı olarak bozuktur ve derlenmez. Hataların bir
kısmı derleme hatası, bir kısmı mantık hatası. Derleyici birincileri size
söyler; ikincileri siz bulacaksınız.

> Bu dosya derleme denetiminin dışında tutulur — bilerek bozuk olduğu için.
