# 5. Hafta — Örnek Kodlar

| Dosya | Konu |
| ----- | ---- |
| `01-ternary.cs` | Ternary operatörü `?:` |
| `02-giris-kontrolu.cs` | `&&` ile iki koşullu kontrol |
| `03-for-dongusu.cs` | `for` döngüsü, geri sayım, adım atlama |
| `04-while-ve-dowhile.cs` | `while` ve `do-while` farkı |
| `05-sayi-tahmin.cs` | Entegre uygulama: `do-while` + `if` + rastgele sayı |
| `06-cift-sayilar.cs` | `for` + `if` bir arada |

## Çalıştırma

```bash
dotnet run 05-sayi-tahmin.cs
```

## Denemeniz için

- `02-giris-kontrolu.cs` içine `Admin` yazın (baş harf büyük). Neden kabul etmiyor?
- `03-for-dongusu.cs` içinde `i <= 10` yerine `i < 10` yazın. Kaç sayı yazdı?
- `04-while-ve-dowhile.cs` içinde `metin = Console.ReadLine();` satırını silin.
  Ne oluyor? **Ctrl + C** ile durdurun.
- `05-sayi-tahmin.cs` neden `while` değil de `do-while` kullanıyor?
- `06-cift-sayilar.cs` aynı işi `if` kullanmadan yapabilir mi?

## Sonsuz döngüde kaldıysanız

Konsol penceresinde **Ctrl + C** tuşlarına basın. Panik yapmayın — bu hatayı
herkes yapar, dönem boyunca birkaç kez daha yapacaksınız.
