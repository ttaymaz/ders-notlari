# 6. Hafta — Örnek Kodlar

| Dosya | Konu |
| ----- | ---- |
| `01-faktoriyel.cs` | Döngüyle biriktirme, `long`, taşma |
| `02-ic-ice-temel.cs` | İç içe döngünün temel mantığı |
| `03-carpim-tablosu.cs` | Klasik uygulama, `\t` ile hizalama |
| `04-sekil-cizme.cs` | Dikdörtgen ve dik üçgen |
| `05-break-continue.cs` | `break`, `continue` ve iç içe döngüde davranışları |

## Çalıştırma

```bash
dotnet run 03-carpim-tablosu.cs
```

## Denemeniz için

- `01-faktoriyel.cs` içinde `long` yerine `int` yazın, `13` girin. Sonuç neden
  negatif çıkıyor?
- Aynı dosyaya `21` girin. `long` bile yetmiyor — buna **taşma** denir.
- `01-faktoriyel.cs` içine `0` girin. Döngü hiç çalışmıyor ama sonuç `1`.
  Neden doğru cevap bu?
- `03-carpim-tablosu.cs` içindeki son `Console.WriteLine()` satırını silin.
  Tablo neden bozuldu?
- `04-sekil-cizme.cs` sonundaki dik üçgen kodunu açın. `j <= i` yazımı neden
  üçgen üretiyor?
