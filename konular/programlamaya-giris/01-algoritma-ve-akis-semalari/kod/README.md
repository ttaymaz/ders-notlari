# 1. Hafta — Örnek Kodlar

Her dosya, aynı klasördeki akış şemasının kod karşılığıdır. Şemayı okuyun,
sonra kodu çalıştırın; hangi kutunun hangi satıra denk geldiğini görün.

| Dosya | Şema | Yapı |
| ----- | ---- | ---- |
| `01-toplama.cs` | `01-dogrusal-akis` | Doğrusal |
| `02-pozitif-negatif.cs` | `02-mantiksal-akis` | Mantıksal (karar) |
| `03-sayac.cs` | `03-dongusel-akis` | Döngüsel |

## Çalıştırma

```bash
dotnet run 01-toplama.cs
```

.NET 10 ile tek bir `.cs` dosyası proje kurmadan çalışır. Visual Studio'da
konsol projesi açmanıza gerek yok; terminalden doğrudan çalıştırabilirsiniz.

Bilgisayarınızda .NET kurulu değilse deponun ana sayfasındaki
**Code → Codespaces** düğmesiyle tarayıcıda açın — kurulum gerektirmez.

## Denemeniz için

- `01-toplama.cs` içinde toplama yerine çarpma yapın.
- `02-pozitif-negatif.cs` sıfır girildiğinde ne yazıyor? Neden? Nasıl düzeltirsiniz?
- `03-sayac.cs` 5 yerine 10'a kadar saysın. Geriye doğru saydırabilir misiniz?

Kodu bozmaktan çekinmeyin. Bozup düzeltmek, okumaktan daha çok öğretir.
